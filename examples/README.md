# Examples

Sample `appcask.config.json` files. Point the CLI at one with:

```bash
cd examples/mdn
appcask doctor
```

| dir | wraps | shows off |
|-----|-------|-----------|
| [`mdn/`](./mdn) | developer.mozilla.org | a plain content site — offline page, downloads, deep links into `/docs/*`, GitHub sign-in handed to the OS browser |

> These configs reference `assets/splash-logo.png` which you supply — `appcask
> doctor` will flag it as missing until you do.
