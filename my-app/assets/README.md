# my-app/assets

Upload your images here (GitHub: "Add file" → "Upload files").

| file | size | notes |
|------|------|-------|
| `icon.png` | 1024×1024, opaque | the launcher / store icon — everything else is generated from it |
| `icon-foreground.png` | 1024×1024, transparent | *optional* — the icon centred with padding, for Android's adaptive (circular / squircle) icon |
| `splash-logo.png` | ~512×512, transparent | *optional* — a logo shown on the splash screen |

No files here? The build uses a plain placeholder icon and a solid-colour splash.
